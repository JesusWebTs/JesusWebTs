## 👋 About me

**Senior Full Stack** software engineer with 5+ years building scalable, modular, security-minded systems across **web, mobile and cloud**. I've shipped CMS platforms, B2B solutions and mobile apps on Android and iOS to production.

Beyond code: I model databases, gather requirements with clients, estimate timelines and budgets, lead teams, and run field tests to understand the product from the user's side.

- 🚗 **La Wawa** — Senior Full Stack (2022 – present): CMS, B2B, Driver App and Rider App
- 🎨 **UXVerse Studio** — Full Stack (2023 – 2026): architecture, estimation and delivery for clients
- 🧭 **Kromatics Design** — Team Lead (2023 – 2025): hardest technical problems, C-level communication, in-house UI kit
- 🤖 I work with **AI agents** (Claude Code, skills and orchestration) as part of my development workflow

## 🏗️ Architecture I designed

<table>
<tr>
<td width="33%" valign="top">

### ⚙️ Interface generator
A type contract **generated by reading the API's source code** (AST of the resolvers) and shipped to **3 web apps and 2 mobile apps** at once. The frontend never hand-writes API types, and a backend change reaches every project fully typed with a single command.

</td>
<td width="33%" valign="top">

### 🎨 UI v2 / design system
I created **La Wawa's UI v2**: a library of abstract components with theming, skeletons and error boundaries by default, shared by the CMS, B2B and partner portal. What I learned designing it helped me build the interfaces of **DaCapo** and **Rewrite AI** from scratch.

</td>
<td width="33%" valign="top">

### 🤖 AI agent architecture
**AIDevCell**: a way of working where a manager splits the requirement, one agent writes, a different one reviews, lint/TS gates run, and every commit is attributed to its agent. Skills for session handoffs, PRs, ClickUp and Slack.

</td>
</tr>
</table>
